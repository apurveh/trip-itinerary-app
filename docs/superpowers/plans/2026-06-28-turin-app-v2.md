# Turin App v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild The Clara & Apurva Files into a usable, info-rich trip tool — fix the invisible-content bug, move to a page-per-day "anchors + menu of ideas" model with a live Today banner, and load the new 8-day Turin plan — without changing the case-file aesthetic.

**Architecture:** Static Vite + React + TS SPA with `HashRouter` (GitHub Pages). Three route levels: Hub `/`, Trip overview `/trips/turin`, Day page `/trips/turin/day/:n`. All trip content lives in one typed data file (`src/lib/trips/turin.ts`). Pure logic (date/clock, maps links, storage) lives in small tested modules under `src/lib/`. No backend, no maps embed, no PWA.

**Tech Stack:** React 18, TypeScript, React Router 6 (`HashRouter`), Tailwind 3 + `globals.css` tokens, Framer Motion, Lucide, Vite. Vitest (added in Task 3) for pure-logic unit tests. Playwright (already available to the operator) for visual/render verification.

## Global Constraints

- **Aesthetic frozen:** reuse the existing case-file system (stickers, tape, stamps, pills, marquee, amber/wine/teal palette in `src/styles/globals.css`). No redesign.
- **Spontaneity model:** days are **fixed anchors + an optional menu of ideas**. Never emit an hour-by-hour schedule. (See memory `travel-style-spontaneous`.)
- **Base of operations:** `Corso Dante 72, Turin` (Dante metro). Nearby supermarkets: Prestofresco, Carrefour Express, Pam Local. All daily transit notes start from Dante.
- **Dates:** 1–8 July 2026. Day n → weekday: Wed 1, Thu 2, Fri 3, Sat 4, Sun 5, Mon 6, Tue 7, Wed 8 Jul.
- **Booked already:** Museo Egizio Thu 2 Jul @ 10:00; Mole Cinema Museum + panoramic lift Sat 4 Jul @ 15:00. Everything else ticketed is "to book."
- **Budget:** concrete fixed costs only (transit, museum tickets, Sacra shuttle bundle, Superga tram, day-trip trains). No groceries/eating-out/aperitivo estimates. De-emphasised.
- **Maps:** tap-to-navigate links only — `https://www.google.com/maps/search/?api=1&query=<encoded>`. No embedded maps.
- **Persistence:** `localStorage` only (packing checkboxes, booking confirmation numbers). No backend/accounts.
- **Currency note:** prices in DKK, `1 EUR ≈ 7.47 DKK`. Show EUR where a real ticket price is known.
- **Routing:** keep `HashRouter`; day links use `#/trips/turin/day/:n`.
- Reference spec: `docs/superpowers/specs/2026-06-28-turin-app-v2-design.md`. Source itinerary: `docs/Copy of Torino plan & info.docx`.

```tsx
import { useEffect, useRef, useState } from "react";
import type { CSSProperties, ReactNode } from "react";

interface RevealProps {
  children: ReactNode;
  delay?: number;
  style?: CSSProperties;
}

export default function Reveal({ children, delay = 0, style }: RevealProps) {
  const ref = useRef<HTMLDivElement>(null);
  // Start in the "to-animate" state only if we can observe; otherwise stay visible.
  const [armed, setArmed] = useState(false);
  const [shown, setShown] = useState(false);

  useEffect(() => {
    const el = ref.current;
    if (!el || typeof IntersectionObserver === "undefined") return;
    setArmed(true); // we CAN animate, so begin hidden then reveal
    const io = new IntersectionObserver(
      (entries) => {
        entries.forEach((e) => {
          if (e.isIntersecting) {
            setShown(true);
            io.unobserve(e.target);
          }
        });
      },
      // forgiving: fire as soon as the top edge enters, even for tall elements
      { threshold: 0, rootMargin: "0px 0px -10% 0px" }
    );
    io.observe(el);
    // Safety net: if nothing fired within 1s (e.g. already on-screen, tall), show anyway.
    const t = window.setTimeout(() => setShown(true), 1000);
    return () => {
      io.disconnect();
      window.clearTimeout(t);
    };
  }, []);

  const cls = armed ? `reveal-anim ${shown ? "in" : ""}` : "reveal";
  return (
    <div ref={ref} className={cls} style={{ transitionDelay: `${delay}ms`, ...style }}>
      {children}
    </div>
  );
}
```

```ts
import type { Day, TripStatus } from "./types";

const DAY_MS = 86_400_000;
const toUTC = (iso: string) => Date.parse(`${iso}T00:00:00Z`);

export function tripStatusAt(nowISO: string, startISO: string, endISO: string): {
  status: TripStatus; dayNumber: number | null; daysUntil: number;
} {
  const now = toUTC(nowISO.slice(0, 10)), start = toUTC(startISO), end = toUTC(endISO);
  const daysUntil = Math.round((start - now) / DAY_MS);
  if (now < start) return { status: "upcoming", dayNumber: null, daysUntil };
  if (now > end) return { status: "completed", dayNumber: null, daysUntil: 0 };
  return { status: "in_progress", dayNumber: Math.round((now - start) / DAY_MS) + 1, daysUntil: 0 };
}

export function nextAnchor(day: Day, nowHHMM: string): Anchor | null {
  const timed = day.anchors.filter((a) => a.time && /^\d{2}:\d{2}/.test(a.time));
  const found = timed.find((a) => (a.time as string).slice(0, 5) >= nowHHMM);
  return found ?? null;
}
```

```ts
import { useState } from "react";

export function useLocalStorage<T>(key: string, initial: T): [T, (v: T) => void] {
  const [value, setValue] = useState<T>(() => {
    try {
      const raw = localStorage.getItem(key);
      return raw != null ? (JSON.parse(raw) as T) : initial;
    } catch {
      return initial;
    }
  });
  const set = (v: T) => {
    setValue(v);
    try { localStorage.setItem(key, JSON.stringify(v)); } catch { /* ignore */ }
  };
  return [value, set];
}
```
